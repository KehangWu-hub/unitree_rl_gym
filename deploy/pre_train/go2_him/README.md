# Go2 HIM模型接口

[项目首页](../../../README.md) · [HIM训练与部署](../../deploy_real/README_GO2_HIM.zh.md)

HIM部署模型将历史编码器与Actor封装为一个TorchScript文件，运行时不需要Critic或训练优化器。

## 模型包

| 文件 | 内容 |
|---|---|
| `policy.pt` | 历史编码器与Actor |
| `deploy.yaml` | 观测顺序、历史、动作、关节映射与控制参数 |
| `provenance.json` | 模型摘要及版本记录 |

同一目录中的模型与参数配套使用。仿真入口通过 `--policy` 和 `--deploy-config` 选择模型包；真机入口通过完整控制配置的 `--config` 选择。

## 输入与输出

输入形状为 `[batch, 270]`：六帧45维观测，最新帧在前。

| 每帧观测顺序 | 维度 |
|---|---:|
| 前进、侧向、偏航指令 | 3 |
| 机身角速度 | 3 |
| 投影重力 | 3 |
| 关节位置相对默认角度 | 12 |
| 关节速度 | 12 |
| 上一策略动作 | 12 |

历史编码器输出3维速度估计和16维归一化隐变量；Actor接收当前观测45维加编码结果19维，共64维。输出为 `[batch, 12]` 关节位置动作。

```text
关节参考目标 = 默认关节角 + 动作缩放 × 策略动作
```

当前模型包动作缩放为0.25，策略PD增益为20/0.5，策略周期为20ms。具体缩放和关节顺序以配套 `deploy.yaml` 为准。

## 训练侧信息

Critic使用238维单帧观测：基础观测45＋真实线速度3＋外部扰动力3＋地形高度187。真实速度同时用于估计器训练；额外仿真信息不进入部署Actor的输入。

训练导出目录结构：

```text
exported/
├── policies/policy.pt
└── params/deploy.yaml
```

替换模型时同时更新接口参数与版本摘要；真机还需同步对应的完整控制YAML和baseline清单。运行命令见[HIM指南](../../deploy_real/README_GO2_HIM.zh.md)。
