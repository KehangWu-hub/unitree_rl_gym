# Go2 v1.0

发布日期：2026-10-12。现场操作者确认此前的方向运动问题已经解决，当前真机运动效果验收成功，本版本据此作为已验收基线。该结论来自现场反馈，不表示每个方向都已取得独立测量的速度、距离或连续运行时长。

## 使用范围

- 默认持续键盘控制：W/S 前后，A/D 侧移，Q/E 行进中转向；换向无需先按 X。
- W 可选 0.50m/s 指令；S/A/D 和 Q/E 平移指令为 0.30m/s，转向指令为 ±0.30rad/s。
- X/空格归零后可继续运动；默认不设累计运动预算。
- C 正常趴下并退出：归零 2 秒、受控降低 5 秒、稳定 2 秒、低姿态阻尼收尾 1 秒。重复 C 不重置过程。
- Z/Ctrl+C 或独立停止终端紧急阻尼退出；C 退出过程中仍可急停。
- 恢复原厂模式前等待连续 1 秒静止低姿态，最多等待 15 秒。

运行及连接说明见 [真机指南](../../deploy/deploy_real/README_GO2.zh.md)。Q/E 包含向前速度，未提供原地转向。版本验收不包含断电、完整物理断网、所有地形或所有接触条件下的可靠性认证。

## 冻结与复核

Git 标签 `v1.0` 保存源代码、测试、文档、策略模型、配置和机器人资产。逐文件 SHA-256 见 [版本清单](../../deploy/deploy_real/configs/go2_v1.0_manifest.json)，其中也记录本地真机证据的路径与摘要；运行日志不随 Git 分发。

原 [前置检查清单](../../deploy/deploy_real/configs/go2_verified_baseline.json) 仍供运行入口核对站姿/零速记录，其中旧短时试验保留为历史证据。更换模型或修改配置后需重新检查，不能仅凭 v1.0 标签沿用旧记录。

复核命令不连接机器人：

```bash
python -m unittest discover -s tests -p 'test_go2*.py'
python deploy/deploy_real/deploy_real_go2.py --check
```

冻结前复核：112 项软件测试中 110 项通过、2 项可选 DDS 集成测试跳过；模型与配置离线加载通过。本地 Unix socket 传输测试在沙箱外运行模拟通信，未连接机器人。历史 MuJoCo 报告仍按原结果保留，本次现场验收不会将历史不通过的仿真报告改成通过。
